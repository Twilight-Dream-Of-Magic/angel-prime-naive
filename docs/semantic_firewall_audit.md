# Semantic Firewall Audit

## Nearest frozen failure classes

The joint optimization was checked against the following nearest barriers:

- **F052:** native-token counts cannot be presented as ordinary bit
  complexity;
- **F057:** an unevaluated operator program cannot be treated as an executed
  factorial effect;
- **F060:** integrity hashes do not replace semantic replay;
- **F062:** Download may not perform deferred native execution and return a
  value that can re-enter the core;
- **F067/F068:** saturated or fixed-width counters cannot support unbounded
  complexity claims;
- **F073:** a compact generator does not make generated polynomial work free;
- **F077:** continuous or rational source relaxation cannot replace the exact
  discrete integral source language.

The supplied Fitting/atom-spectrum dependency audit is retained as external
structural literature only.  No Fitting ideal, atom spectrum, monoform test,
or global-section selector participates in the Wilson consumer.  In
particular, none of those detector/certificate charts is promoted into a
native child generator or used to steer the factorial state.

## New state and transition role

No new native state is introduced. The new object is an ordinary
Download-side consumer bound to an already certified native factorial view.
Its transition is:

```text
verified native factorial view
    -> irreversible ordinary modular projection
    -> Wilson residue/decision
```

The native state remains immutable. The result has no ascent conversion.

## Why prior counterexamples do not transfer

1. **No compact-program laundering.** The implementation executes the complete
   block polynomial, multipoint reductions and scalar reconstruction. Every
   generated polynomial event is charged.
2. **No hash-as-proof.** The native coordinate is independently replayed; the
   hash/seal is only one integrity component.
3. **No deferred native execution in Download.** Download performs an ordinary
   observation of a frozen native result and cannot produce another native
   state.
4. **No counter saturation.** New counters use checked addition and
   multiplication. A saturated polynomial counter is rejected.
5. **No rational relaxation.** Complement pairing and all polynomial work stay
   in integer modular rings. No field inverse is used.
6. **No prime/composite hidden split.** The same theorem and polynomial engine
   are used for every modulus. Only the parity already present in the native
   factor count selects the exact integral reconstruction formula.
7. **No candidate-derived factor count.** The factor count comes from the
   certified native rank. The candidate serves only as modulus and the exact
   consistency condition `candidate == rank + 1`.
8. **No derived-observation authority.** A transported observation is accepted
   only by comparison with the canonical closed state. It has no transition
   that can overwrite or advance that state.

## Complexity delta

The release reports native, modular-ring, fixed-word, memory, exact-integer and
output costs separately. The result is classified as a strict local Pareto
improvement in the same asymptotic class; no polylogarithmic claim is made.
