# Code and Manuscript Audit

## Verdict

The core mathematical identities and the executed Wilson residue path are
correct in the reviewed scope. The original 36-page manuscript was not yet a
clean mathematical-annals article because theorem, software conformance,
release bookkeeping, and toolchain evidence appeared at the same narrative
level.

## Engineering findings repaired in this revision

1. The legacy materialized-coordinate ledger counted one block-sized array even
   though the reconstructed baseline owns both an evaluation-point array and a
   block-value array. The corrected count is
   `block_coefficients + 2 * full_blocks`; streamed tail work is not called
   stored space.
2. Transform/CRT multiplication and fast monic remainder were exercised only
   indirectly by the Wilson growth probe. A dedicated differential test now
   compares them with independent schoolbook references for composite and
   near-maximum 64-bit moduli.
3. The default parallel per-prime transform path lacked a direct equivalence
   test. Serial/parallel equality is now required.
4. A downloaded primitive observation vector was terminal but had no explicit
   public comparison against its canonical closed state. The additive
   `validate_download_packet` interface now rejects a modified derived map and
   the test verifies that such modification leaves the canonical state intact.
5. The term `allocation_count` could be read as a process-wide heap count. The
   documentation now limits it to tracked outer-schedule objects; transform
   scratch remains charged by the conservative peak bound.
6. The source volumes contained history arithmetic, singular division, causal
   paths and class-quantum packets, but no single explicit three-class axiom
   layer bound those ideas to all four operations and public executable
   functors. The revision adds ten axioms, HADD/HSUB/HMUL/HDIV, complete maze
   states, native/history/future-quotient functors, structural
   superposition/interference/cancellation, exact minor entanglement
   certificates, and dedicated positive and negative tests.

## Publication repair

The 162-page mathematical annals article now leads with the authorial/formal
boundary of Angel, the SN--OFCS precursor, definitions, ten axioms, ordered
fold multiplication, theorems, proof roadmaps, and scoped non-claims.
Difficult proofs and the source-to-revision map are in technical appendices.
Raw counter tables, CI/toolchain facts, hashes, and finite test matrices remain
in evidence appendices and the separate colored engineering audit. The two
documents cross-reference each other without treating tests as proof.
